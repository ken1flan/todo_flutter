# todo_flutter

A new Flutter project.

## セットアップ手順

1. [FVM](https://fvm.app/)でFlutterのバージョン管理を行っています。
   - Flutterコマンドは `fvm flutter <command>` で実行してください。
2. 必要なツール:
   - fvm, dart, flutter, VSCode (推奨: Dart, Flutter, Copilot拡張)
3. AndroidビルドにはAndroid StudioとSDKが必要です。
   - Android SDK 36とBuildTools 28.0.3をインストールしてください。
   - 詳細: https://flutter.dev/to/macos-android-setup
4. 初回セットアップ例:
   ```sh
   fvm install stable
   fvm use stable
   fvm flutter pub get
   fvm flutter run
   ```
